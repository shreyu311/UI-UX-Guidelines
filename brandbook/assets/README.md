# Brand assets

Optional folder for files your brand book refers to, for example:

- `logo.svg` (full logo) and `logo-mark.svg` (symbol only), preferably SVG
- PNG exports for tools that don't accept SVG
- reference screenshots listed in the brand book's "Reference screens" section

Only add files you own or are licensed to share. Font files are often licensed for use but not for redistribution; check the license before committing them, or link to the font's source instead.
