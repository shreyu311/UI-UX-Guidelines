# Changelog

All notable changes to this UI/UX guidelines template.

---

## [1.0.0] — 2026-06-07

### Added
- Open template structure with `BRANDBOOK.md` for company customization
- `CUSTOMIZATION.md` fork-and-adapt guide
- `assets/` folder for logo and brandbook files
- Standards chapters: scope, brand/tokens, style card, components, governance
- `ACCESSIBILITY.md` — WCAG 2.1 AA compliance matrix
- `DEVELOPER_HANDOFF.md` — code examples and API specs
- `DESIGN.md` and `AGENTS.md` for AI tooling integration
- MIT license

### Removed
- All company-specific branding and internal project artifacts
- Planning & Meetings notes
- Pilot projects and prototypes
- Archived/superseded governance docs

---

## How to update

Add entries under `[Unreleased]` as you customize, then cut a version when you release to your team.

```markdown
## [Unreleased]

### Added
- Your change here

### Changed
- Your change here
```
