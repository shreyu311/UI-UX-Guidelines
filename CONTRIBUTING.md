# Contributing

This is a personal project maintained by [@shreyu311](https://github.com/shreyu311). Issues and pull requests with corrections and improvements are welcome.

## Before you open a pull request

- **Keep it brand-agnostic.** No real company names, brand colors, fonts, logos, or product details. Use clearly fictional examples.
- **Only contribute what you have the right to share.** Don't paste content from employers, clients, or other people's design systems.
- **Write rules in the existing style:** a MUST, SHOULD, or MAY level and a stable rule ID (see [`docs/customization.md`](docs/customization.md#changing-a-rule)).
- **Don't weaken MUST rules** below WCAG 2.2 AA.
- **Keep one source of truth:** rules in `DESIGN.md`, brand fields in the template, checklist items in `docs/validation.md`. Link instead of copying.
- **Update [`CHANGELOG.md`](CHANGELOG.md)** under "Unreleased".
- **Check that relative links work.**

## Reporting a problem

Open an issue that names the file, the rule ID if there is one, and what's wrong or unclear.
